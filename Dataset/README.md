# Dataset Directory

The German Traffic Sign Recognition Benchmark (GTSRB) dataset can be downloaded from:
- **Kaggle**: [GTSRB - German Traffic Sign Recognition Benchmark](https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign)

Extract the dataset files here if you wish to retrain the CNN model using `python traffic_sign.py`.
The pre-trained model weights are already provided in `Model/traffic_classifier.h5`.
